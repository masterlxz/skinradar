# SkinRadar

Extensão de navegador (uso pessoal) para analisar sob demanda anúncios de skins de CS2 em
marketplaces (DashSkins.gg, DashSkins.com.br, RentSkins.com.br), comparando o preço de compra com
anúncios ativos, vendas recentes e Buy Orders do CSFloat, e calculando lucro líquido e ROI.

> **Status: pré-projeto.** O PRD está registrado; nenhum código ainda. A Fase 1 (prova de
> viabilidade dos dados do CSFloat) vem antes de qualquer extensão.

- Requisitos: [`project/PRD.md`](project/PRD.md)
- Estado do projeto: [`project/OVERVIEW.md`](project/OVERVIEW.md)
- Pendências: [`project/PENDING.md`](project/PENDING.md)

Princípio: nenhuma consulta automática durante a navegação; toda análise começa num clique.
